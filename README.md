## App Overview
This webapp decodes virtually any car's Vehicle Identification Number (VIN).
Enter a 17 character VIN and click/tap on the Decode button.
Scroll down to view the results.

Well suited for decoding Tesla VINs.

## Device Compatibility
This webapp is responsive so will work on any common device, including smartphones, tablets, laptops, and desktops - whether they are Apple, Android, Linux, Microsoft Windows etc.
